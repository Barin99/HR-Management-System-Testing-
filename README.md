# HR Management System Testing

## About the Project
This project focuses on manual testing of a Human Resource Management System (HRMS) to verify application functionality, data accuracy, and reliability. It includes test case preparation, test execution, bug reporting, and SQL-based database validation.

## Objectives
- Validate employee management functionalities and business requirements.
- Identify functional defects through positive, negative, and boundary testing.
- Verify employee records and data consistency using SQL queries.
- Document test results and report defects systematically.

## Scope of Testing
- Employee registration and record creation
- Employee information updates and deletion
- Employee search and record retrieval
- Input field validation and error handling
- Database consistency and data validation

## Testing Activities
- **Test Planning:** Identify test scenarios based on application requirements.
- **Test Case Design:** Prepare test cases with preconditions, steps, expected results, and actual results.
- **Test Execution:** Execute test cases and record pass/fail status.
- **Defect Reporting:** Document defects with reproduction steps, severity, and priority.
- **SQL Validation:** Execute SQL queries to verify stored records and data consistency.
- **Regression Testing:** Re-test affected functionalities after defect fixes.

## Tech Stack
- **Testing:** Manual Testing, Functional Testing, Regression Testing
- **Database:** SQL, SQL Server
- **Documentation:** Microsoft Excel
- **Concepts:** SDLC, STLC, Test Case Design, Defect Life Cycle, Data Validation

## Sample Test Scenarios
| Test Scenario | Expected Result |
|---|---|
| Add a new employee with valid details | Employee record is created successfully |
| Submit the form with mandatory fields missing | Appropriate validation messages are displayed |
| Search using a valid employee ID | Correct employee record is displayed |
| Update existing employee details | Updated information is saved correctly |
| Verify employee data using SQL | Database records match the expected values |

## Project Deliverables
- Test scenarios and test cases
- Test execution results
- Bug reports and defect documentation
- SQL queries for database validation
- Test summary report

## Key Learnings
- Understanding manual testing methodologies and software quality assurance.
- Designing test cases for positive, negative, and boundary conditions.
- Using SQL queries to validate database records.
- Documenting defects and communicating test results clearly.
